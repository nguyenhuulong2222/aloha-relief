# Aloha Relief

Small, supervised disaster micro-grants on PayPal. **Rules check. AI explains. People decide.**

> Demo: PayPal sandbox money and fictional people only ("Kanaloa Relief Fund").

Work in progress for the PayPal "Build What's Next with PayPal and AI" hackathon. Full README, architecture and
run instructions land before submission. See [docs/PLAN.md](docs/PLAN.md) for the plan.
